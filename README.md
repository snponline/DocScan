# DocScan

สแกนเอกสารด้วย iPhone แล้วส่งเข้าโฟลเดอร์บนคอม Windows ผ่าน Wi-Fi ในบ้าน/ร้าน — ไม่ผ่านคลาวด์ ไม่ต้องมีบัญชี ฟรี

- ถ่ายรูป → ตรวจขอบกระดาษและตัดให้ตรงอัตโนมัติ (ลากมุมปรับเองได้)
- ฟิลเตอร์ พื้นขาว ตัวหนังสือชัด: "สีธรรมชาติ" (แนะนำ), "สแกนแบบ Notes", สีชัด, ขาว-เทา, ขาวดำ
- บันทึกเป็น **JPG** หรือ **PDF** (หลายหน้ารวมเป็นไฟล์เดียวได้) ความละเอียดราว 290 dpi บน A4
- เลือกโฟลเดอร์ปลายทางบนคอมได้ ประมวลผลภาพในเครื่องทั้งหมด

## ดาวน์โหลด (Windows)

โหลด `DocScan.zip` จาก [Releases](../../releases/latest) แตกไฟล์ แล้วดับเบิลคลิก `DocScan.exe` — อ่านวิธีใช้ใน `อ่านก่อน.txt` ในไฟล์ zip
(Windows อาจเตือน SmartScreen เพราะโปรแกรมไม่ได้เซ็นรับรอง: กด "More info" → "Run anyway")

## ใช้งาน

1. เปิด `DocScan.exe` — เบราว์เซอร์จะเปิดหน้าตั้งค่า เลือกโฟลเดอร์ที่จะเก็บไฟล์ (ค่าเริ่มต้น `Documents\DocScan`, ถ้า Documents อยู่ใน OneDrive จะใช้ `C:\Users\<ชื่อ>\DocScan`)
2. iPhone (Wi-Fi เดียวกับคอม) สแกน QR หรือเปิดลิงก์ใน **Safari** แล้วถ่ายเอกสาร → กด "ส่งเข้าคอม"

ข้อมูลทั้งหมดอยู่ในเครือข่ายของคุณ ลิงก์/QR มีรหัสเฉพาะเครื่อง ไม่ควรเปิดพอร์ตออกอินเทอร์เน็ต

## รันจากซอร์ส / build เอง

ต้องมี Python 3 (ใช้ไลบรารีมาตรฐาน; `qrcode` ไม่บังคับ ใช้วาด QR)

```
python server.py            # หรือดับเบิลคลิก start_scan_server.bat
python build_exe.py         # ต้องมี PyInstaller + qrcode → release\DocScan\DocScan.exe และ DocScan.zip
```

ตัวแปรแวดล้อม: `DOCSCAN_PORT` (พอร์ต, ค่าเริ่มต้น 8780), `DOCSCAN_HOME` (ที่เก็บ config.json; exe ใช้ `%APPDATA%\DocScan`)
